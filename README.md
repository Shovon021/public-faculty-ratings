# East West University — Faculty Evaluation Platform

An independent, student-driven platform providing 100% anonymous faculty evaluations to help EWU students make informed section choices with confidence during advising.

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (Turbopack) & React 19
- **Styling:** Tailwind CSS & Lucide Icons
- **Backend / Auth:** Google Firebase & Firestore
- **Security:** Verified student institutional authentication & strict Firestore rules

## 🔒 Security & Privacy
- **100% Anonymous:** Reviewer identities and emails are completely detached from public reviews.
- **Institutional Verification:** Only verified EWU CSE students (@std.ewubd.edu) can post reviews.
